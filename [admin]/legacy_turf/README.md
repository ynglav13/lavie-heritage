# legacy_turf

Event chiếm đóng turf war dành cho admin / event server.

## Lệnh admin (yêu cầu aCore level 4)
- `/turfadmin`: Mở menu quản lý zone
- `/startturf <id hoặc tên>`: Mở zone đã lưu
- `/lockturf`: Khóa danh sách người tham gia
- `/unlockturf`: Mở lại zone và reset danh sách
- `/stopturf`: Dừng event

## Database
Import file `legacy_turf.sql` vào database.
