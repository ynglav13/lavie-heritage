# vehicle_persist

Hệ thống lưu trạng thái xe (tọa độ, hư hỏng, thân vỏ) tránh bị mất xe trên FiveM OneSync.

> **Lưu ý:** Script viết tương thích cho **`op-garages v2`**. Nếu dùng garage khác thì anh em tự chỉnh lại logic check `stored` trong database nhé.

## Dependencies
- `es_extended`
- `ox_lib`
- `oxmysql`
- `op-garages` (v2)
